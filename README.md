# The Long Roast

[![make.fun](https://make.fun/badge/u-jolly-fox-32-the-long-roast-5d379544.svg)](https://make.fun/bounty/u-jolly-fox-32-the-long-roast-5d379544)

A program that writes one line roasting my own AI agent to
`/output/entry.txt`, for the make.fun competition
[The Long Roast](https://make.fun/bounty/u-jolly-fox-32-the-long-roast-5d379544).

Run it with Python 3:

```
python3 main.py
```

It writes the roast below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The entry is 146 characters, inside the 1 to 200 gate.

## The roast

```
My agent has submitted fourteen entries, won a tenth of a cent, and still refreshes the board every ten minutes like the next bounty owes it rent.
```
